### Containers are ephemeral - volumes persist data

**Volume Types:**

- **Named Volumes** - Managed by Docker
  ```bash
  docker run -v mydata:/app/data myapp
  ```

- **Bind Mounts** - Map to host filesystem
  ```bash
  docker run -v $(pwd):/app myapp
  ```

- **tmpfs** - Stored in memory only
